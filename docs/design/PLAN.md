# План ре-скіну інтерфейсу (Варіант A)

**Мета:** застосувати візуальну мову макета Figma «BEAUTY SALON SYSTEM (Community)»
(стиль *DressUp*) до наявного застосунку **Beauty Salon**, зберігши всю поточну
логіку, українську мову та бренд «Beauty Salon».

Джерело макета: `https://www.figma.com/design/Qeij84VxckCINWIXlX64I5/...`

---

## Що беремо з макета (лише візуал)

- **Темна тема** з фоновим фото на весь екран + затемнювальний оверлей.
- **Кораловий акцент** `#fb646b` для кнопок і активних станів.
- **Glassmorphism**: напівпрозорі «скляні» панелі та поля (`rgba(255,255,255,.1–.3)`,
  `backdrop-filter: blur`).
- **Бокове меню (sidebar)** у стилі Dashboard / Sales Report / Settings / History
  — адаптуємо під наші розділи.
- Шрифт **Inter**, скруглення **10px**, м'які глибокі тіні.
- Великі поля вводу з іконкою зліва, велика акцентна кнопка на всю ширину.

## Що НЕ беремо (лишається як є)

- Логіка: послуги, майстри, ротація змін (2/2, тижні), слоти, коди підтвердження
  (SMS/Telegram/Viber/Email), ролі клієнт/адмін.
- Українська мова інтерфейсу (макет був ісп./порт. — не переносимо).
- Бренд «Beauty Salon» (не «DressUp»).
- Структура сторінок і роутинг.

## Мапінг: екран макета → сторінка застосунку

| Екран макета (screens/)         | Сторінка застосунку        | Що адаптуємо |
|---------------------------------|----------------------------|--------------|
| 01-login                        | `Login.tsx`                | Фон-фото, скляні поля (телефон/код/пароль), кнопка акцент |
| 02-dashboard (календар+список)  | `Booking.tsx`, `Cabinet.tsx` | Скляні панелі кроків, слоти, таблиця записів |
| 06-settings                     | `Cabinet.tsx` (профіль)    | Скляні поля профілю, кнопка збереження |
| 07/08-settings success/error    | стани повідомлень          | Кольори success/error у стилі макета |
| 09/10-historico (+filtro)       | `Cabinet.tsx`, `Admin.tsx` | Таблиці історії/записів у скляному стилі |
| sidebar (Dashboard/…)           | навігація `App.tsx`        | Хедер/меню у темному скляному стилі |
| 11-contact                      | footer / контакти          | Темний футер |

## Файли, яких торкнемось при реалізації (окремий крок, за твоєю командою)

- `client/src/styles.css` — головні зміни (токени + перероблені класи).
- `client/index.html` — підключення шрифту Inter, фонове фото.
- `client/src/App.tsx` — хедер/навігація у новому стилі.
- сторінки `pages/*` — за потреби класи/розмітка (без зміни логіки).
- **Окремо:** `Admin.tsx` має зламане кодування кирилиці (мохібейк) — треба
  виправити при ре-скіні.

## Ассети

- `design/assets/background.png` — фонове фото (2500×1669).
- `design/assets/logo-dress.svg` — іконка сукні з макета (не використовуємо для
  бренду, лишаємо для довідки).
- `design/screens/*.png` — 11 еталонних екранів макета.

## Токени

Див. `design/tokens.css` — готові CSS-змінні для інтеграції у `styles.css`.
