## 1. Палітра «фіалка» — ролі ЗАФІКСОВАНО (2026-09-08)

Ключове правило контрасту (WCAG AA на темному): `#7851A9` — **лише для заливок**
(кнопки, активні стани, фони-акценти), **ніколи як текст** на темному фоні. Текст-акцент — світліший
(`#C8A2C8` / `#DA70D6`).

**Ролі кольорів:**
- `#7851A9` — основний акцент-**заливка** (`--accent`): `.btn.primary`, активні `.tab`/`.slot`, `.cal-day--sel`, фони-акценти.
- `#5D3A5A` — темний фіалковий, hover-заливка (`--accent-dark`).
- `#DA70D6` (orchid) — яскравий акцент-**текст**/лінки/hover, градієнтна пара (`--accent-2`).
- `#C71585` (medium violet red) — акцент-контраст, важливі бейджі (`--accent-contrast`).
- `#C8A2C8` (thistle) — приглушений текст (`--muted`).
- `#E6E6FA` (lavender) — світлі підписи / база для `--text-dim` і `--glass-*` (`--lavender`).
- `#4B61D1` — синій інфо-акцент (резерв для інфо-станів; використовувати за потреби).
- `#FFFFFF` — головний текст (`--text`).
- `#722F37` (wine) — deep-контраст/помилки (`--wine`).
- `#FFD700` / `#F3E5AB` — **у РЕЗЕРВІ** (не вводимо токени зараз; додамо точково лише за потреби — напр. зірки рейтингу).
- `#FFD1DC` (pink lace) — м'які підсвітки (резерв, за потреби).

**Токени `styles.css` — перевизначити наявні + ДОДАТИ нові (`:root`, темна тема):**
```
/* перевизначаємо наявні */
--accent: #7851A9;                       /* був #fb646b */
--accent-dark: #5D3A5A;                  /* був #e8555c */

--muted: #C8A2C8;                         /* був #87888c */
--text-dim: rgba(230, 230, 250, 0.6);    /* lavender-прозорий (був rgba(255,255,255,.6)) */
--glass-10: rgba(230, 230, 250, 0.10);   /* скло на lavender-базі (було white) */
--glass-15: rgba(230, 230, 250, 0.15);
--glass-30: rgba(230, 230, 250, 0.30);
--bg-dark: #1e1526;                       /* темний фіалковий фон (був #202020) */
--bg-overlay: rgba(30, 21, 38, 0.55);
--ok: #6fcf7c;                            /* лишаємо зелений «робочий/підтверджено» */
/* ДОДАЄМО нові (їх немає в :root) */

`--bg` / `--card` / `--border` вже посилаються на токени вище — перефарбуються самі.

**Градієнти `body` (styles.css:50-53) — правимо КОЛІРНІ значення** (структуру/селектор не чіпаємо; це

linear-gradient(160deg, #262626, #202020, #1a1a1a) → фіалкові тони (#241a2e, #1e1526, #160f1d)
```

**Не-брендові семантичні кольори поза токенами** (рішення 2026-09-08: **зсуваємо від коралу**, лишаючи
семантику):
- `.error` (styles.css:107-109): `#ff8a80` / `rgba(255,100,107,…)` — лишається «червоною помилкою», але
  перевести на `--wine`-гаму (напр. текст `#e88` → лишити читабельним; фон/рамку на `rgba(114,47,55,…)`),
  щоб не кораловіло. Помилка семантично червона — це ок.
- `.status.Cancelled` (~139): `rgba(255,100,107,…)` → `--wine`-гама (скасовано = приглушено-червоне).
- `.status.Completed` (`#9aa6ff`) і `.status.PendingVerification` (`#ffc94d`) — **лишити** (сині/жовті
  семантично доречні; не кораль). `.status.Confirmed` — зелений `--ok`, лишити.

### 1а. Групування Services/Pricing — за наявним `category` (факт перевірено)

`Service.Category` існує і на сервері (`"hair" | "manicure"`), і в клієнті (`types.ts`: `category: 'hair' | 'manicure'`).
Групуємо **за ним**, нове поле не вводимо. Реальних категорій **дві** (не 4, як у макеті BELEZA — там ще
«макіяж»/«SPA», яких у даних немає). **Неіснуючі категорії не вигадуємо.** Мапа на людські назви + SVG-іконки:
- `hair` → «Перукарські послуги» (іконка ножиць);
- `manicure` → «Манікюр і педикюр» (іконка блиску/лаку).
Якщо згодом додадуть категорії — секція масштабується з даних автоматично.

## 2. Обсяг та стратегія

Ключове спостереження: у `styles.css` уся службова частина (форми, `.step`, `.table`, `.status`, `.calendar`, картки майстрів, хедер, футер) зав'язана на CSS-змінні (`--accent`, `--glass-*`, `--bg-dark` тощо). Тому **зміна теми = перевизначення значень токенів**, без переписування самих правил (узгоджено з AGENTS.md §6: «доповнювати, не переписувати»).

Лендинг з макета верстаємо **власним JSX + нові CSS-класи** (з префіксом, напр. `.lp-*`), щоб не чіпати наявні класи.
