# План-задача: вікно бронювання 14 → 28 днів (4 тижні)

Актуально на **2026-09-07**. Статус: **план, не реалізовано**. Код лишається на 14 днях до окремого дозволу на виконання.

---

## 1. Рішення

Офіційний перехід вікна бронювання і графіка з **14 днів на 28 днів (4 тижні)**. Реалізується через **одну константу** `ScheduleService.WindowDays = 28`, щоб бекенд і фронтенд лишались узгодженими. Синхронно оновлюються заборони в `AGENTS.md` §11 і в документі `master-schedule-booking-fix.md` §6 (інакше правила суперечитимуть коду).

---

## 2. Обсяг

Зміна константи + текстові описи «14 днів» → «28 днів / 4 тижні» + синхронізація дефолту фронтенду + оновлення двох заборон. Логіку ротації, зайнятості, форму відповідей API **не чіпати** — розширення вікна коректне саме тому, що `RotationHelper.WorksOn` рахує будь-яку дату, а решта коду прив'язана до `WindowDays`.

**Файл:** `server/Services/ScheduleService.cs`
- `public const int WindowDays = 14;` → `= 28;`
- Оновити XML-коментар: «поточний + наступний тиждень» → «4 тижні наперед».
- Місця, що вже використовують `WindowDays` (`GetSlotsAsync`, `GetMasterScheduleAsync`, `PreviewRotation`, `ValidateAsync` через `> WindowDays`) — **правити не треба**, вони підхоплять константу автоматично.

### Крок 2 — Бекенд: текстові описи «14 днів»

- `server/Controllers/BookingController.cs` — коментар: «Вільні слоти на 14 днів…» → «на 28 днів…».
- `server/Controllers/CatalogController.cs` — коментар `masters/{id}/schedule`: «Графік майстра на 14 днів…» → «на 28 днів…».

## 4. Перевірка (§12 AGENTS.md)

1. `dotnet build server` — 0 warnings, 0 errors.
2. `cd client; npm run build` — tsc + vite без помилок.
3. Слоти: `POST /api/booking/slots` (обидва режими — `masterId` заданий і `null`) повертають слоти на 28 днів, форма відповіді незмінна.
5. `GET /api/catalog/masters/{id}/schedule` повертає 29 днів (сьогодні + 28), як і слоти.
6. Час: перевірити межу доби (23:30 за Києвом) і обидва типи ротації (`Weekly`, `TwoTwo`) — останній тиждень вікна має коректну ротацію.
7. Календар на фронтенді малює 4 тижні без місячної навігації, сітка Пн–Нд ціла.
