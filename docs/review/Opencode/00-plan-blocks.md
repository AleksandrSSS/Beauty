Фази 9–11 можна другою ітерацією, але `ReminderWorker + Master.IsActive` (1 рядок з Фази 10) беру одразу з C.

## Правила для всіх блоків (з AGENTS.md)

1. Не комітити і не пушити без явного запиту.
2. Не створювати `global.json`, `Dockerfile`, тестовий проєкт, не чіпати `styles.css` крім доповнення.
3. Час тільки через `SalonClock`, у БД UTC. Нові ендпоінти з часом — ISO-8601 з `Z`.
4. JSON: `camelCase` + enum рядками. Помилки `{ "error": "українською" }`.
5. Нові ендпоінти — явний `[Authorize]` / `[Authorize(Roles="Admin")]` / `[AllowAnonymous]`.
6. `BookingController.Create` — транзакцію `Serializable` не чіпати.
7. Перед «готово» по блоку: `dotnet build server`, `npm run build`, smoke з § «Перевірка» кожного файлу блока.
8. Стверджую «працює» тільки про те, що реально запускав.
