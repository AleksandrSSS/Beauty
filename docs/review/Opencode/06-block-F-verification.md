# Блок F — наскрізна перевірка (Фаза 12)

Джерело: `masters-feature-plan.md` §18. Залежність: блоки D і E.

## Мета

Довести що нічого не зламано і новий функціонал проходить end-to-end. Автотести не входять (покриття 0, за окремим запитом).

## Кроки

### F1. Автокоманди (§18.1)

```powershell
dotnet build server
dotnet ef migrations list --project server
cd client; npm run build
```

Очікування: білд без нових warning'ів проти заміру з блока A; міграції `InitialCreate + AddMasterPhotoUrl` застосовані; `tsc + vite` без помилок.

### F2. Smoke Фази 0 (§6.3.1–6.3.8)

Повторити повністю: `admin-login` 200 (BCrypt після апгрейду), catalog 200 з enum-рядками, `request-code → verify-code → appointments`, `slots` в обох режимах, `create → confirm` з `Serializable`, клієнт 4 роути без помилок консолі.

### F3. Сценарій «клієнт» (§18.3)

Головна 6 майстрів (2+ з фото, решта ініціали) → клік → `/masters/:id` з графіком до вибору послуги → послуга → слоти тільки робочих днів → слот → `/booking` на підтвердженні → `/login` по `devCode` → повтор вибору → бронювання → код → `/cabinet` з правильним записом → скасування → слот знову вільний.

### F4. Сценарій «адмін» (§18.4)

Вхід → новий майстер (`TwoTwo`, якір сьогодні, послуги, «як у салону», прев'ю 2/2) → збереження → фото → головна і `/masters/:id` → бронювання клієнтом в іншій вкладці → «Звільнити» → impact з кандидатами → `Reassign` → запис у нового, майстер неактивний → кабінет клієнта з новим майстром + `NotificationLogs` → `isActive=true` повертає на головну.

### F5. Матриця безпеки (§18.5)

| Перевірка | Очікуване |
|---|---|
| `POST photo` без токена | 401 |
| `POST photo` токеном клієнта | 403 |
| 5 МБ | 400, файл не збережено |
| `.txt` як `.jpg` | 400 |
| `filename="../../appsettings.json"` | 200, згенероване ім'я, поза папкою чисто |
| `GET /uploads/masters/../../appsettings.json` | 404 |
| `GET schedule` | 200, без `client/phone/service` |
| `GET deactivation-impact` без токена | 401 |

### F6. A11y і адаптив (§18.6)

320/375/768/1440: картки, шапка, слоти, таблиці. Tab: картка/слоти/чекбокс з видимим фокусом. `alt` у всіх `img`, fallback `aria-hidden`. Текст `--text/--muted`, не `--text-dim` на фото.

## Критерій готовності всього плану

F1–F6 зелені + smoke F2 + обидва сценарії без втрати даних. Неперевірене називаю неперевіреним. Коміт/пуш тільки за явним запитом.

Оцінка: 2–3 год.
